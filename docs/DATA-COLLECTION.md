# 统计公报采集（数据线说明）

> 江山图鉴自己的数据线：收集每个地级行政区、每个省级行政区和全国 2020–2025 年的《国民经济和社会发展统计公报》，
> 从正文中逐句提取指标，每个数值都带着原句和出处。第一阶段使用的 chinaciv 汇编（`pipeline/sources/city_stats.py`）
> 只用于 2023 年互校，不作为基准覆盖我们自己的数据。

## 一、原则

1. **只用官方数字**：统计局（或政府）发布的公报原文。转载站只作为“抄件”，必须注明原发布机关。
2. **缺失就是空（null）**：公报没写的指标一律为空，**绝不写 0**，也**绝不拿别的年份补**。
3. **每个数字带原句**：`quote` 是公报里的整句原文（全角数字照抄），另有转载页网址、原发布统计局和发布时间。
4. **2023 年是互校年**：与 chinaciv 的 2023 年数值对照，发现差异就回到原文核对，而不是用对方的值覆盖。
5. **图片不识别**：只有图片的公报只记录图片地址（`image_only`），不做 OCR，留待人工或后续处理。

以上原则由 `python -m pipeline check`（`pipeline/check.py`）逐条检查：全部采集结果的每条记录、每个数字，以及设计定稿原型的全部城市数据。`all` 的最后一步就是它；每次提交时，测试也会用真实样本和故意造的违反把每条规则跑一遍。

## 二、来源与年份覆盖

| 年份 | 主要来源 | 方式 | 说明 |
|---|---|---|---|
| 2020–2023 | 中国统计信息网 tjcn.org 转载件 | 本机抓取：`pipeline/sources/tjcn_bulletins.py` | 按年度索引页 + 各省公报列表页；每篇注明“来源：XX市统计局” |
| 2024、2025 | 各地统计局 / 政府官网（gov.cn） | 项目负责人在大陆网络下运行 `tools/local_fetch/fetch_bulletins.py` | tjcn 至今没有转载 2024 年及以后的公报；本机无法访问 gov.cn 与搜索引擎 |
| 2020–2023 的缺口 | 同上 | 同上（`targets.json` 里 `reason` 为 `missing_on_tjcn` / `image_only_on_tjcn` / `attachment_only_on_tjcn`） | 只有图片或附件的，`known_urls` 给出统计局自己的图片/附件地址，脚本直接下载 |
| 2023（互校） | chinaciv 汇编（固定提交） | `pipeline/sources/city_stats.py` | 只比较，不合并 |

**tjcn.org 的抓取细节**

- 年度索引：2020 `/tjgbsy/nd/36541.html`，2021 `/36944.html`，2022 `/37292.html`，2023 `/37660.html`（GBK 编码）。
  索引表每行先是省（或第一行的“中国”），后面是该省各市；按行内的省份 + 名称匹配代码，因此 2022 年放在 `08jl`
  文件夹下的吉林市也能正确对上。
- 各省列表页（`/tjgb/03hb/`、`index_2.html` …，新到旧）一直翻到只剩 2020 年以前的公报为止，用来补上索引里漏掉的篇目。
- 每篇公报的所有分页（`xxx_2.html` …）都会下载；正文取 `<td id="text" class="xwnr">`。
- 只能用明文 HTTP（HTTPS 会被对方重置）。本机经代理的 CONNECT 隧道访问 80 端口，见 `pipeline/core/fetch.py`
  模块说明；一次只发一个请求，间隔 1 秒，全部缓存在 `data/raw/tjcn_bulletins/`，不重复下载。
- 名称陷阱：海南州（青海 海南藏族自治州）≠ 海南省；吉林市 ≠ 吉林省；自治州简称“延边州”“迪庆州”；内蒙古的“盟”；
  新疆、西藏的“地区”。匹配总是在已知省份内进行，见 `pipeline/parse/places.py`。
- 新疆生产建设兵团的公报不对应任何地级代码，记为“未匹配”。

## 三、指标定义

所有数值换算成下表的标准单位；`raw` 字段保留公报原样的数字和单位（如 `3186933万元`）。

| 字段 | 指标 | 单位 | 采用的写法 | 不采用 |
|---|---|---|---|---|
| `gdp` | 地区生产总值（全国为国内生产总值），现价 | 亿元 | 生产总值、地区生产总值（GDP）；万元、万亿元自动换算 | 人均生产总值、万元GDP能耗、民营/数字/海洋经济增加值、季度与上年核实数 |
| `gdp_primary` / `gdp_secondary` / `gdp_tertiary` | 第一、二、三产业增加值 | 亿元 | “第一产业（完成）增加值…”，“第一、二、三产业增加值分别为…” | 占比、增速 |
| `gdp_growth` | 地区生产总值实际增长率 | % | GDP 同句中、数值之后的“（按不变价格计算）比上年增长/下降 x%”，“持平”为 0 | 名义（现价）增长 |
| `population` | 年末常住人口 | 万人 | 常住（总）人口、常住人口总量；全国为“年末全国人口”；“人”自动换算 | 户籍人口、城镇/乡村常住人口、普查公报句 |
| `population_registered` | 年末户籍人口（公安户籍登记） | 万人 | 户籍人口、户籍总人口、户籍人口数、总人口（户籍人口）；“户籍人口总户数…万户，总人口…万人”；同一句注明“根据户籍人口统计/按公安户籍人口统计/据公安部门统计”的总人口 | 常住户籍人口、户籍常住人口（常住人口中有本地户籍的部分，如深圳、上海）、城镇/乡村户籍人口、户籍出生人口、未注明口径的“总人口” |
| `urbanization` | 常住人口城镇化率 | % | 城镇化率、城镇人口占（常住）总人口比重 | 户籍人口城镇化率，“超过60%”这类非精确值 |
| `gdp_per_capita` | 人均地区生产总值（公报写明的数） | 元 | 人均地区生产总值、人均生产总值、人均GDP；“万元”自动换算 | 用 GDP 和人口自己算出来的值 |
| `income` | 全体居民人均可支配收入 | 元 | 全体/全市/城乡居民人均可支配收入 | 中位数、人均消费支出 |
| `income_urban` | 城镇（常住）居民人均可支配收入 | 元 | 含“城镇和农村居民…分别为A和B元” | |
| `income_rural` | 农村（常住）居民人均可支配收入 | 元 | 含农村牧区、农牧民 | |
| `budget_revenue` | 一般公共预算收入 | 亿元 | 一般公共预算（地方级）收入；旧称“公共财政预算收入”“一般预算收入” | 全口径财政收入、财政总收入、地方财政收入（口径不同） |
| `retail_sales` | 社会消费品零售总额 | 亿元 | 社会消费品零售总额（完成/实现） | 限额以上零售额；只有增速时为空 |

取值规则：按阅读顺序取第一个“关键词 + 同一分句内的数字和单位”；跳过讲别的年份（句首“2022年，……”）、季度、半年、
“最终核实/修订”说明和普查的句子；“突破5000亿元，达到5123.4亿元”取后者。正文没有时，再看表格行
（“地区生产总值 | 亿元 | 1234.5”）。全部规则与真实例句见 `pipeline/parse/bulletin.py` 和 `tests/test_bulletin_parse.py`。

**校验标记（`flags`）**

- `sum:+1.8%`：三次产业之和与 GDP 相差超过 1%；
- `range:<字段>`：超出城市 / 省 / 全国的合理范围（如城市人口不在 0.05–4000 万人之间）；
- `order:income_rural>urban`、`order:income_all`：收入大小关系不合理；
- `title_mismatch`：页面标题里没有该地名或年份。

标记只提示，不删除数值；有标记的记录需要回到原文核对。

## 四、记录格式与出处

每个（地区代码，年份）一条记录：

```json
{
  "code": "130100", "name": "石家庄市", "level": "city", "province": "130000", "year": 2023,
  "source": "tjcn_bulletins", "status": "text",
  "url": "http://www.tjcn.org/tjgb/03hb/37692.html",
  "title": "石家庄市2023年国民经济和社会发展统计公报",
  "bureau": "石家庄市统计局", "published": "2024-04-07 13:33:40", "dated": "2024-03-11",
  "images": ["http://tjj.sjz.gov.cn/images/…jpg"], "attachments": [],
  "fields": {
    "gdp": {"value": 7534.2, "unit": "亿元", "raw": "7534.2亿元",
            "quote": "初步核算，全年全市生产总值7534.2亿元，按不变价格计算，比上年增长6.1%。"},
    "retail_sales": null
  },
  "fields_found": 12, "flags": [],
  "files": ["tjcn_bulletins/pages/03hb/37692.html"]
}
```

- `status`：`text`（有正文）、`image_only`（正文只有统计局自己网站的图片，`images` 记录地址）、`attachment_only`
  （只有 PDF/Word 附件链接，`attachments` 记录地址）、`missing`（没有这篇公报）。
- `bureau`：原发布机关（tjcn 页头“来源”，或官网页面的“来源/发布机构”）；`published`：页面发布时间；
  `dated`：公报正文开头印的日期。
- `files`：所用原始文件，相对 `data/raw/`；每个文件的网址、sha256、大小、下载时间见对应文件夹的 `manifest.json`。
- 本地采集的记录另有 `local`（搜索引擎、搜索词、下载时间、页面标题是否匹配）。

**输出文件**（`data/interim/bulletins/`，不入库，可随时重建）

| 文件 | 内容 |
|---|---|
| `sources/<来源>/<年份>.json` | 每个来源各自的记录 |
| `<年份>.json` | 合并后的记录：每个代码一条，取最好的一条（有正文 > 附件/图片 > 缺失；再比指标数、标记数；同等时官网原页优先于转载），其余列在 `other_sources` |
| `coverage.csv` | 每个（代码，年份）一行：状态、来源、找到的指标数、缺的指标、校验标记、网址、发布机关 |
| `crosscheck_2023.csv` / `.json` | 与 chinaciv 2023 年 GDP、三次产业、常住人口的逐项对照（相对差 > 0.1% 记为不一致） |

## 五、怎样运行

在仓库根目录：

```bash
# 1. tjcn.org 2020–2023（首次约 1,550 个请求，间隔 1 秒，实测约 50 分钟；之后全部走缓存）
python -m pipeline fetch city_stats            # chinaciv 互校数据（若未缓存）
python -m pipeline fetch tjcn_bulletins
python -m pipeline process tjcn_bulletins      # → data/interim/bulletins/…

# 2. 生成本地采集清单（2024、2025 全部 + 2020–2023 缺口）
python3 tools/local_fetch/make_targets.py      # → tools/local_fetch/targets.json

# 3. 项目负责人在自己电脑上运行（见 tools/local_fetch/README.md），得到 jiangshan_bulletins_<日期>.zip
#    把 zip 放进 data/raw/local_bulletins/ 后：
python -m pipeline fetch local_bulletins       # 记录 zip 的 sha256 并安全解压
python -m pipeline process local_bulletins     # 解析并与 tjcn 记录合并

# 4. 测试
python -m pytest tests/
```

`--offline` 时 tjcn 来源只使用已缓存的页面。所有读取下载文件的脚本都只把它们当数据解析，不执行任何内容。

## 七、已知局限

- 2020 年是普查年，多数城市公报只给户籍人口，常住人口与城镇化率大多为空（这是原文如此，不是漏抓）。
- 有的公报把主要指标放在图片或附件里：图片不识别；本地采集的 .docx 用标准库读出正文，.pdf 只有装了可选的
  `pypdf` 才读。
- 有正文但写法罕见的句子可能漏抓（字段为空，`coverage.csv` 的 `missing_fields` 会列出），不会填错别的年份的数。
- 本地采集依赖搜索引擎：在境外网络、开着代理，或被搜索引擎要求验证时，会有较多“未找到”，可用 `--retry` 重试。
