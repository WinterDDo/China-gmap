> 2026-11-27 经 CEO 评审（扩展模式）与两轮调研确定。设计语言见 `docs/DESIGN.md`，延后事项见 `TODOS.md`。

## 一句话

**以地方为中心的中国城市档案**：一座城的经济、人口、治理、历史放在同一张千里江山地图上，每条信息都能追溯到官方原文；能比较、能看流动、能一键分享。地图是入口和外壳，档案是内核。

## 为谁（国内为主，界面中英双语）

| 人群 | 想完成的事 | 我们给的 |
|---|---|---|
| 应届生、换城的年轻人 | 该去哪座城 | 城市对决、收入与房价、产业区牌、人口流向 |
| 高考家庭 | 选哪座城读书 | 高校落图、产业对口、城市档案 |
| 博主、记者、老师 | 讲清楚一座城、一组对比 | 分享长卷、A3 海报、开放数据（带出处） |
| 关心时政与地方的人 | 谁在治理、从哪里来 | 治理档案与干部交流图（见红线） |
| 每个人 | 家乡的来历 | 古今同图：沿革与历代名宦、名人 |

## 为什么是我们（差异化）

1. **以地方为中心**：现有工具要么只讲经济（统计门户、鸥维、新一线），要么只讲官员（人民网资料库、学术库、组织部广场），要么只在学术圈（CBDB/CHGIS）。没人把它们挂在同一个地方。
2. **流动视角**：人口流向、干部交流、历史人物宦游，都是地图上的线——表格做不到。
3. **古今同图**：千里江山画风天然契合历史；敏感度低，文化认同强。
4. **可信 + 好看 + 好玩**：每个数字附原文；画面能传播；交互像游戏。
5. **免费、开放、双语**：对标日本 RESAS、英国 ONS Explore Local Statistics、美国 Data USA；中国目前空缺。

## 数据原则

- 统计数字只用官方口径；**基准年 2025，序列 2020–2025**；缺失留空，不以他年替代。
- 采集：中国统计信息网（tjcn.org）批量取公报原文（同时注明转载页与原发布机关）；对不上或缺失的城市，用用户在国内本机运行的脚本从统计局官网取原件兜底。
- 每个数字可追溯到具体文件（URL、日期、sha256）；百科“数据来源”自动生成。

## 治理层红线（不可越过）

1. 只用官方公开来源，每条附原文链接与日期。
2. 只覆盖省、地两级主要领导（党委书记、政府主要负责人），不涉及中央领导层。
3. 不收录落马、处分、司法信息；不画关系网；不推断派系；不展示“共事”。
4. 不给官员打分、不做政绩排行；任期与经济曲线并列时注明“并列不代表因果”。
5. 只记公职履历，不涉家庭、财产、私生活。
6. 人物唯一编号（区分同名），标注截至日期，提供纠错入口。
7. 治理层是独立数据文件 + 开关，国内版在审图要求下可整层不带。

本项目**保持非商业**；若将来商业化，历史层数据需另行授权或替换。

## 上线路线

两步走：先 GitHub Pages 公开测试；同时把边界换成自然资源部标准地图服务依据、准备审图号材料；成熟后申请审图号与 ICP，国内正式部署。
