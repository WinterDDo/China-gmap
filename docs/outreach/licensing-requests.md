## 1. 致 CBDB

**Subject:** Permission request: non-commercial public display of CBDB data in an open-source map of Chinese cities

Dear Dr. Wang,

My name is [Your name]. I am building **Jiangshan Atlas (江山图鉴)**, a free, non-commercial, open-source website that presents each Chinese prefecture-level city on an interactive map painted in the style of *A Thousand Li of Rivers and Mountains*: its economy and population from official statistics, and its history. [Project link, if public]

We would like to add a history layer that shows, for each modern city, notable historical figures who held office there or were born there, and draws a person's career as a route across the map (for example, Su Shi's postings). CBDB is by far the best source for this, and we would like to use it properly.

What we plan to do:
- Use person names, dynasty and years, office postings with their places, and native places.
- Show a few facts per person and link back to the CBDB record.
- Credit CBDB on every page that uses it, with the release we used and the citation you prefer.
- Keep the project non-commercial. If we publish a derived dataset, release it under CC BY-NC-SA 4.0.
- Send corrections we find back to the project.

Our questions:
1. Is this use acceptable under CC BY-NC-SA 4.0 for the releases that carry it? Which is the latest such release?
2. Your licensing terms of 20 August 2026 for the current release follow the no-derivatives provisions. May we use the current release for this kind of public display (selected fields, reshaped for a map)? If not, is there a way to request permission?
3. How would you like CBDB to be cited on the site?

Thank you for building CBDB and making it available.

Best regards,
[Your name]
[Email]

## 2. 致 CHGIS

**Subject:** Permission request: non-commercial public display of CHGIS V6 in an open-source map of Chinese cities

Dear CHGIS team,

My name is [Your name]. I am building **Jiangshan Atlas (江山图鉴)**, a free, non-commercial, open-source website that presents each Chinese prefecture-level city on an interactive map painted in the style of *A Thousand Li of Rivers and Mountains*. [Project link, if public]

We would like to add a history layer: a time slider showing how prefectures and county seats changed across dynasties, and each modern city's line of predecessors. CHGIS V6 is the authoritative source for this. Its terms permit free academic use but not redistribution, so we are asking for permission before using it.

What we plan to do:
- Use the V6 time-series prefecture and county-seat data.
- Draw simplified boundaries and seat points on the public map. To be transparent: a web map sends simplified geometry to the visitor's browser. We would not offer the data as a download.
- Credit CHGIS (Harvard University and Fudan University) with the version and citation you prefer, on every page that uses it.
- Keep the project non-commercial, and send historical corrections we find to the editors at Fudan.

Our questions:
1. May we use CHGIS V6 for this kind of public display?
2. If sending simplified geometry to the browser is a concern, would rendered map images (tiles) be acceptable instead?
3. How would you like CHGIS to be cited?

Thank you for this remarkable resource.

Best regards,
[Your name]
[Email]
