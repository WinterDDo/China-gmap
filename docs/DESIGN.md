# 设计语言 · Design Language

本项目只有**一套**设计语言、一种风格：**千里江山**（绢本设色）。

| | 千里江山 |
|---|---|
| 材质 | 绢底、矿物颜料、墨线、朱砂印 |
| 地图 | 赭石平原 → 石绿山腰 → 石青峰顶，海面工笔水纹，邻国留白 |
| 强调 | 朱砂印（唯一的强调色） |
| 透镜 | 墨分五色（清、淡、重、浓、焦）表达多少；石青 ↔ 朱砂表达增减 |

深色主题（曾提案“万家灯火”）已按用户意见**暂不做**。页面在浅色与深色的系统设置下都显示同一种千里江山风格。任何颜色都只能来自 `web/css/tokens.css` 的设计变量（地图画布读取同一套变量）。

> 下文中标注“夜”的条目为暂停的深色主题保留的记录，当前实现不使用。

工作名称：**江山图鉴 · Jiangshan Atlas**（可改）。

---

## 1. 色彩 Color

所有颜色都是**有名字的颜料**，按角色使用，不按“好看”使用。

### 1.1 角色变量（界面）

| 变量 | 角色 | 昼 | 夜 |
|---|---|---|---|
| `--ground` | 页面与地图底色 | 绢 `#efe4ca` | 夜 `#070b14` |
| `--leaf` | 面板（册页）底 | 熟绢 `#f4ecd9` | 夜幕 `rgba(12,18,31,.9)` |
| `--leaf-sunk` | 面板内凹区（输入框、表格条纹） | `#e9ddc2` | `#121b2c` |
| `--ink` | 主文字 | 焦墨 `#2b231d` | 月白 `#ece4d2` |
| `--ink-2` | 次文字 | 淡墨 `#5d4e40` | `#a9b4c8` |
| `--ink-3` | 注释、刻度 | 清墨 `#8a7a68` | `#6d7a92` |
| `--rule` | 细线、分隔 | `rgba(58,46,38,.22)` | `rgba(150,190,255,.16)` |
| `--accent` | 唯一强调色：选中、印章、关键数字 | 朱砂 `#b23a2b` | 灯火 `#ffc476` |
| `--accent-ink` | 强调色上的文字 | 绢 `#fbf1e4` | 夜 `#1a1208` |
| `--water` | 海、湖 | 青瓷 `#d3dfd2` | `#070c16` |
| `--river` | 河流、链接 | 黛 `#305c6c` | 夜青 `#4d78b8` |

### 1.2 矿物颜料（地图专用）

石青 `#2d5e78` · 石绿 `#5b927f` · 赭石 `#b07a45` · 藤黄 `#d9a43c` · 朱砂 `#b23a2b` · 墨 `#1c1612` · 蛤白 `#f6f2e8`

夜间对应：夜青 `#6f9cff` · 苔光 `#6fc3a8` · 琥珀 `#d9a066` · 灯黄 `#ffcf73` · 灯火 `#ffc476` · 夜墨 `#05080f` · 月白 `#e8eef7`

### 1.3 数据色阶

- **顺序（大小、多少）**：昼用“墨分五色”——同一种墨在绢上的五个浓度：清 `.06` · 淡 `.17` · 重 `.32` · 浓 `.50` · 焦 `.72`（墨 `#1c1612` 的不透明度）。夜用“色温”：`#4f7dff → #8fb3ff → #e8e4d8 → #ffcf73 → #ff8a4c`。
- **发散（增减）**：昼 石青（减）↔ 绢（零）↔ 朱砂（增）；夜 冷蓝（减）↔ 夜（零）↔ 琥珀（增）。语义固定：**冷 = 少/减，暖 = 多/增**。
- **无数据**：昼为斜向细墨线（“未着色的绢”），夜为全暗。从不用 0 的颜色表示“无数据”。
- 一张图只用一种色阶。图例永远写出单位、年份和出处。

## 2. 字体 Typography

| 角色 | 字体 | 用途 |
|---|---|---|
| 题字 Brush | 马善政楷书 Ma Shan Zheng | **只**用于品牌字、题跋、印文 |
| 标题 Display | 思源宋体 Noto Serif SC 600/900 | 面板标题、省名、城市名、大数字 |
| 正文 UI | 思源黑体 Noto Sans SC 400/500/700 | 界面文字、表格、数值（`tabular-nums`） |

- 字号阶梯（px）：11 · 12.5 · 14 · 16 · 20 · 26 · 34。不另造字号。
- 英文模式沿用同一套字体（思源宋体/黑体自带拉丁字形），保证中英文质感一致。英文小标题用大写、字距 `.12em`。
- 地图注记遵循传统制图：省名为宋体、加大字距（中文 `.4em`）、淡墨；城市名为宋体加绢色描边（昼）或黑体细体加夜色描边（夜）；水体名用黛色、字距加大。

## 3. 母题 Motifs

每个母题只表达一种意思，不作装饰滥用。

1. **印 Seal**：唯一的“强调”记号。用于：品牌标、GDP 前十城市、选中的城市、当前透镜、百科章节号。印文永远是汉字（英文模式下英文写在印旁）。昼为朱砂实心方印（石刻磨损）；夜为同形的“灯”：琥珀色细框 + 光晕 + 琥珀印文。
2. **裱 Mounting**：所有面板都是“册页”：册页底色、外细线 + 内 3 px 处第二条细线（双线框），圆角 2 px。昼用纸的轻微投影；夜用毛玻璃 + 双线框。不使用其它卡片样式。
3. **墨线 Ink line**：所有图标是 20 px 网格、1.5 px、圆头线描，颜色取 `currentColor`。不使用 emoji，不使用填充图标。
4. **水纹 Ripple**：只表示水。海面、湖面，以及加载状态。
5. **题跋 Colophon**：地图左上角的竖排标题 + 小印，相当于画作的题款；中文模式竖排，英文模式横排两行。

## 4. 版式 Layout

- 地图铺满全屏；顶栏 48 px（品牌 | 全国产出 | 搜索 | 中/EN | 昼/夜 | 分享 | 百科）。
- 右侧详情面板 380 px（册页），手机上为底部抽屉。
- 左下角透镜坞（当前透镜的印 + 图例直方图）；右下角为地图内的南海诸岛附图与比例尺。
- 间距只用 4 的倍数：4 · 8 · 12 · 16 · 24 · 32。

## 5. 动效 Motion

- 界面过渡 200 ms `cubic-bezier(.2,.7,.2,1)`。
- 面板展开像**展卷**：从右向左 `clip-path` 展开，320 ms。
- 选中城市时**钤印**：印章 1.12 → 1 倍缩放并回正 2°，180 ms。
- 切换透镜：墨色晕开（交叉淡入 240 ms）。
- `prefers-reduced-motion` 时全部改为直接切换。

## 6. 双语 Bilingual

- 一次只显示一种语言，顶栏 `中 / EN` 切换；写入地址栏（`lang=en`）与本地存储。品牌字永远中英并列。
- 地名：中文用简称（“延边”），英文用国家标准拼写（汉语拼音；少数民族语地名用官方音译，如 Ürümqi、Hohhot、Lhasa）。
- 数字：中文用 万 / 亿 / 万亿；英文用 thousand / million / billion / trillion 的缩写（K / M / B / T）与 ¥。
- 所有界面字符串集中在 `web/js/i18n.js`，不在组件里写死。

## 7. 数据诚实 Honesty

- 空值永远显示“—”，不画成 0。
- 每个数字可追溯到“百科 → 数据来源”中的具体文件。
- 地图疆域依据标准地图数据；南海诸岛附图不得遮挡台湾；陆地国界与海岸线用不同画法。

## 8. 游戏感与图标优先 Game feel & icons first（用户要求，第 3 版加入）

原版好玩，靠的是**像游戏**和**图标优先**。本项目在千里江山风格里保留这两点：

- **五赋**：人（常住人口）· 金（GDP，铜钱）· 粮（第一产业，稻穗）· 工（第二产业，工坊）· 商（第三产业，天平）。每种是一枚颜料圆章 + 绢色图形，地图、顶栏、面板、排行榜共用同一套图形（`YIELDS`，同一份路径数据同时生成 SVG 与画布图形）。
- **城池四级**（按常住人口）：村 < 300 万 · 城 300–800 万 · 府 800–1500 万 · 都 ≥ 1500 万。界画画法：赭色城墙、石青屋顶、朱红门楼、宝塔。
- **匾额旗标**：漆框匾 + 黑底人口数；GDP 前十为朱漆金字匾；放大后匾下显示五赋；选中城市在匾旁钤印。
- **奇观**：世界遗产画成小幅界画/山水，画在所在地（正式版按全部名录与公开规则选取）。
- **透镜是图标按钮**，名称只在当前透镜与悬停提示中出现。
- **交互**：拖动平移、滚轮/双击/双指缩放（以指针为中心），细节按级展开（全国 → 郡国 → 州府 → 城郭）；悬停城池显示五赋卡片，开透镜时悬停土地勾出地级区；点城池镜头飞过去、钤印、展卷；点顶栏徽章弹出全国前十榜，点一行飞过去；键盘 `/` `+` `−` 方向键 `Esc`。
- **文字只作补充**：能用图形表达的不用文字；文字用于名称、数值、出处。

## 9. 信息架构 Information Architecture（设计评审 Pass 1 加入）

### 9.1 产品结构

地图是唯一的“主场景”，永远在；其余一切都是叠在地图上的册页，关掉就回到地图。

```
江山图鉴
├─ 地图（主场景）
│   ├─ 顶栏 48px：品牌 │ 五赋 ×5（点 → 排行榜）│ 年号 │ 搜索 │ 中/EN │ 顾问 │ 分享 │ 百科
│   ├─ 题跋（左上，仅全国视图）
│   ├─ 缩放与“全国”按钮（右上）· 当前级别（全国 / 郡国 / 州府 / 城郭）
│   ├─ 透镜坞（左下）：透镜图标按钮 + 图例直方图
│   ├─ 南海诸岛附图 + 比例尺（右下，永不遮挡台湾）
│   ├─ 城市卷（右侧 380px）：概况 │ 城区 │ 市民 │ 比较
│   └─ 省卷（右侧 380px，与城市卷同一位置、同一结构）：概况 │ 城市 │ 比较
├─ 顾问 · 六部（左侧停靠 560px，见 9.5）
│   ├─ 户部 · 度支 · 工部 · 司农 · 礼部 · 舆图：每部一句结论 + 一张主图 + 排名表，与地图双向联动
│   └─ 探索器：任选指标 → 表格 + 散点图，选中的城市在地图上高亮
├─ 排行榜（顶栏五赋下拉）：全国前十，点一行飞过去
├─ 搜索（下拉）：城市、省份；中文、拼音首字母、英文名都能搜
├─ 百科（模态册页）：关于 │ 地图说明 │ 五赋与城池规则 │ 透镜 │ 奇观入选规则 │ 数据来源
└─ 分享（小册页）：复制当前视图链接 │ 下载当前视图图片（带题跋与出处）
```

URL 片段保存完整视图：`#city=310000&lens=pc&at=x,y,zoom&lang=en&view=districts`，任何画面都能直接分享。

### 9.2 每个画面先看什么

| 画面 | 第一眼 | 第二眼 | 第三眼 |
|---|---|---|---|
| 地图（全国） | 设色山河 + GDP 前列城市的匾额 | 顶栏五赋（全国总量） | 透镜坞（可以换个角度看） |
| 地图（放大） | 城池图形与匾额 | 匾下五赋 | 地级区边界与奇观 |
| 城市卷 | 印 + 城名 + 城池图形 | 五赋一行（带全国名次） | 当前分页内容 |
| 省卷 | 省名 + 省内城市数 | 五赋一行（34 省中的名次） | 省内城市按 GDP 排的匾额列表 |
| 顾问 | 本部一句结论（“东部 10 城贡献了全国 38% 的 GDP”这类真实算出的句子） | 主图 | 排名表 |
| 排行榜 | 第 1–3 名（金银铜） | 横条长度 | 数值 |

### 9.3 城市卷分页

| 分页 | 内容 | 数据 |
|---|---|---|
| 概况 | 五赋一行、人均 GDP、人口变化、三产结构、全国名次、出处 | 2023 统计公报、七普 |
| 城区 | 按产业专业化给城市挂“区牌”（科技园、金融区、港区、工业园、文旅区、农垦区……）和一枚城市类型徽章（如“工业重镇”“商贸都会”）；规则写在百科 | 分行业就业或增加值（统计年鉴、经济普查），覆盖不全时见 Pass 2 的“部分数据”状态 |
| 市民 | 一排排小人：按年龄、受教育程度、职业、城乡分组，每个小人代表固定人数 | 七普分地区资料 |
| 比较 | 规模相近的 5 城、与省均和全国的对比条 | 已有数据 |

### 9.4 省卷

结构与城市卷相同，避免学两套：概况（五赋、34 省名次、城镇化率）│ 城市（省内城市匾额列表，点击飞过去）│ 比较（与相邻省份）。进入方式：点击地图上的省名，或在搜索中选省份。

### 9.5 顾问 · 六部（决定：六部古称 + 现代副标题；左侧停靠半屏）

```
┌ 顶栏 ─────────────────────────────────────────────────────────────┐
├──────────── 顾问 560px ───────────┬──────── 地图（可操作）───────┬ 城市卷 ┤
│ [户][度][工][农][礼][舆] │ [探]   │                                │(可选)  │
│ 户部 · 人口                        │   ← 表格行悬停：城市在地图上亮起 │        │
│ “七普以来，东部 10 城人口增加       │   → 地图上点城/圈选：表格与图跟随 │        │
│   1,2xx 万，东北减少 xxx 万。”     │                                │        │
│ [主图]                             │                                │        │
│ [排名表 · 可排序 · 点行飞过去]       │                                │        │
└────────────────────────────────────┴────────────────────────────────┴────────┘
```

| 部 | 副标题 | 主题与主图 | 数据 |
|---|---|---|---|
| 户部 | 人口 Population | 人口增减地图 + 七普年龄金字塔、城镇化 | 七普、2023 公报 |
| 度支 | 经济 Economy | “前 N 城贡献全国 X% GDP”的累计曲线、人均 GDP 排名 | 2023 公报 |
| 工部 | 工业与能源 Industry & energy | 第二产业、发电装机按燃料、矿产 | 统计公报、能源数据（后续阶段） |
| 司农 | 农业与土地 Farming & land | 耕地/林地/草地占比（卫星）、第一产业、粮食产量（省级） | ESA WorldCover、统计公报 |
| 礼部 | 教育与文化 Education & culture | 高校、R&D、世界遗产、5A 景区 | 教育部、科技部、文旅部、UNESCO（后续阶段） |
| 舆图 | 交通 Transport | 机场吞吐、港口吞吐、高铁 | 民航局、交通运输部（后续阶段） |
| 探 | 探索器 Explorer | 任意两项指标的散点图 + 表格；刷选即在地图高亮 | 全部已收录指标 |

- 每部用一枚印作页签（印文即部名首字）；当前页签钤朱砂，其余为墨框印。
- **结论句必须由数据实时算出**，并在句末标注年份与出处；数据不足时不写结论，改为说明缺什么。
- 顾问打开时：透镜坞移到顾问右侧（不被遮挡）；城市卷可同时打开，地图在两者之间仍可拖动缩放；地图宽度 < 480px 时自动收起城市卷。
- 手机上顾问为全屏册页，底部固定“看地图”按钮，点一行时先收起册页再飞过去。
