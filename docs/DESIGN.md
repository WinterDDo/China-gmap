# 设计语言 · Design Language

本项目只有**一套**设计语言、一种风格：**千里江山**（绢本设色）。

| | 千里江山 |
|---|---|
| 材质 | 绢底、矿物颜料、墨线、朱砂印 |
| 地图 | 赭石平原 → 石绿山腰 → 石青峰顶，海面工笔水纹，邻国留白 |
| 强调 | 朱砂印（唯一的强调色） |
| 透镜 | 墨分五色（清、淡、重、浓、焦）表达多少；石青 ↔ 朱砂表达增减 |

深色主题（曾提案“万家灯火”）已按用户意见**暂不做**。页面在浅色与深色的系统设置下都显示同一种千里江山风格。任何颜色都只能来自 `web/css/tokens.css` 的设计变量（地图画布读取同一套变量）。

> 下文中标注“夜”的条目为暂停的深色主题保留的记录，当前实现不使用。

工作名称：**江山图鉴 · Jiangshan Atlas**（可改）。

---

## 1. 色彩 Color

所有颜色都是**有名字的颜料**，按角色使用，不按“好看”使用。

### 1.1 角色变量（界面）

| 变量 | 角色 | 昼 | 夜 |
|---|---|---|---|
| `--ground` | 页面与地图底色 | 绢 `#efe4ca` | 夜 `#070b14` |
| `--leaf` | 面板（册页）底 | 熟绢 `#f4ecd9` | 夜幕 `rgba(12,18,31,.9)` |
| `--leaf-sunk` | 面板内凹区（输入框、表格条纹） | `#e9ddc2` | `#121b2c` |
| `--ink` | 主文字 | 焦墨 `#2b231d` | 月白 `#ece4d2` |
| `--ink-2` | 次文字 | 淡墨 `#5d4e40` | `#a9b4c8` |
| `--ink-3` | 注释、刻度 | 清墨 `#8a7a68` | `#6d7a92` |
| `--rule` | 细线、分隔 | `rgba(58,46,38,.22)` | `rgba(150,190,255,.16)` |
| `--accent` | 唯一强调色：选中、印章、关键数字 | 朱砂 `#b23a2b` | 灯火 `#ffc476` |
| `--accent-ink` | 强调色上的文字 | 绢 `#fbf1e4` | 夜 `#1a1208` |
| `--water` | 海、湖 | 青瓷 `#d3dfd2` | `#070c16` |
| `--river` | 河流、链接 | 黛 `#305c6c` | 夜青 `#4d78b8` |

### 1.2 矿物颜料（地图专用）

石青 `#2d5e78` · 石绿 `#5b927f` · 赭石 `#b07a45` · 藤黄 `#d9a43c` · 朱砂 `#b23a2b` · 墨 `#1c1612` · 蛤白 `#f6f2e8`

夜间对应：夜青 `#6f9cff` · 苔光 `#6fc3a8` · 琥珀 `#d9a066` · 灯黄 `#ffcf73` · 灯火 `#ffc476` · 夜墨 `#05080f` · 月白 `#e8eef7`

### 1.3 数据色阶

- **顺序（大小、多少）**：昼用“墨分五色”——同一种墨在绢上的五个浓度：清 `.06` · 淡 `.17` · 重 `.32` · 浓 `.50` · 焦 `.72`（墨 `#1c1612` 的不透明度）。夜用“色温”：`#4f7dff → #8fb3ff → #e8e4d8 → #ffcf73 → #ff8a4c`。
- **发散（增减）**：昼 石青（减）↔ 绢（零）↔ 朱砂（增）；夜 冷蓝（减）↔ 夜（零）↔ 琥珀（增）。语义固定：**冷 = 少/减，暖 = 多/增**。
- **无数据**：昼为斜向细墨线（“未着色的绢”），夜为全暗。从不用 0 的颜色表示“无数据”。
- 一张图只用一种色阶。图例永远写出单位、年份和出处。

## 2. 字体 Typography

| 角色 | 字体 | 用途 |
|---|---|---|
| 题字 Brush | 马善政楷书 Ma Shan Zheng | **只**用于品牌字、题跋、印文 |
| 标题 Display | 思源宋体 Noto Serif SC 600/900 | 面板标题、省名、城市名、大数字 |
| 正文 UI | 思源黑体 Noto Sans SC 400/500/700 | 界面文字、表格、数值（`tabular-nums`） |

- 字号阶梯（px）：11 · 12.5 · 14 · 16 · 20 · 26 · 34。不另造字号。
- 英文模式沿用同一套字体（思源宋体/黑体自带拉丁字形），保证中英文质感一致。英文小标题用大写、字距 `.12em`。
- 地图注记遵循传统制图：省名为宋体、加大字距（中文 `.4em`）、淡墨；城市名为宋体加绢色描边（昼）或黑体细体加夜色描边（夜）；水体名用黛色、字距加大。

## 3. 母题 Motifs

每个母题只表达一种意思，不作装饰滥用。

1. **印 Seal**：唯一的“强调”记号。用于：品牌标、GDP 前十城市、选中的城市、当前透镜、百科章节号。印文永远是汉字（英文模式下英文写在印旁）。昼为朱砂实心方印（石刻磨损）；夜为同形的“灯”：琥珀色细框 + 光晕 + 琥珀印文。
2. **裱 Mounting**：所有面板都是“册页”：册页底色、外细线 + 内 3 px 处第二条细线（双线框），圆角 2 px。昼用纸的轻微投影；夜用毛玻璃 + 双线框。不使用其它卡片样式。
3. **墨线 Ink line**：所有图标是 20 px 网格、1.5 px、圆头线描，颜色取 `currentColor`。不使用 emoji，不使用填充图标。
4. **水纹 Ripple**：只表示水。海面、湖面，以及加载状态。
5. **题跋 Colophon**：地图左上角的竖排标题 + 小印，相当于画作的题款；中文模式竖排，英文模式横排两行。

## 4. 版式 Layout

- 地图铺满全屏；顶栏 48 px（品牌 | 全国产出 | 搜索 | 中/EN | 昼/夜 | 分享 | 百科）。
- 右侧详情面板 380 px（册页），手机上为底部抽屉。
- 左下角透镜坞（当前透镜的印 + 图例直方图）；右下角为地图内的南海诸岛附图与比例尺。
- 间距只用 4 的倍数：4 · 8 · 12 · 16 · 24 · 32。

## 5. 动效 Motion

- 界面过渡 200 ms `cubic-bezier(.2,.7,.2,1)`。
- 面板展开像**展卷**：从右向左 `clip-path` 展开，320 ms。
- 选中城市时**钤印**：印章 1.12 → 1 倍缩放并回正 2°，180 ms。
- 切换透镜：墨色晕开（交叉淡入 240 ms）。
- `prefers-reduced-motion` 时全部改为直接切换。

## 6. 双语 Bilingual

- 一次只显示一种语言，顶栏 `中 / EN` 切换；写入地址栏（`lang=en`）与本地存储。品牌字永远中英并列。
- 地名：中文用简称（“延边”），英文用国家标准拼写（汉语拼音；少数民族语地名用官方音译，如 Ürümqi、Hohhot、Lhasa）。
- 数字：中文用 万 / 亿 / 万亿；英文用 thousand / million / billion / trillion 的缩写（K / M / B / T）与 ¥。
- 所有界面字符串集中在 `web/js/i18n.js`，不在组件里写死。

## 7. 数据诚实 Honesty

- 空值永远显示“—”，不画成 0。
- 每个数字可追溯到“百科 → 数据来源”中的具体文件。
- 地图疆域依据标准地图数据；南海诸岛附图不得遮挡台湾；陆地国界与海岸线用不同画法。
